# Embedded Training – ATmega16 & LPC214x

This repository contains small practice programs written while learning **embedded systems programming** on two microcontroller platforms:

- **ATmega16 (AVR)**
- **LPC214x (ARM7)**

The code is organized into modules that follow incremental exercises typically used when learning embedded development. Each folder contains small standalone examples focusing on a specific peripheral or concept.

---

## Structure

### ATmega16
Exercises implemented on the ATmega16 microcontroller:

- **4.2 First project – LED blink**
- **4.4 Timer, compare match, interrupts**
- **4.5 7-segment display**
- **4.7 UART interface**
- **4.9 Analog to Digital Converter (ADC)**

### LPC214x
Equivalent exercises implemented on the LPC214x ARM-based microcontroller:

- **4.3 LEDs and basic I/O**
- **4.4 Timer, compare match, interrupts**
- **4.5 Seven segment display**
- **4.6 UART**
- **4.9 ADC**

---

## Purpose

The goal of this repository is to document **step-by-step practice with embedded peripherals**, including:

- GPIO / LED control
- Timers and interrupts
- Seven-segment displays
- UART communication
- Analog-to-Digital Conversion (ADC)

Each example focuses on a **single concept**, allowing gradual familiarization with the hardware and development environment.

---

## Notes

- These programs are **learning exercises**, not full applications.
- Each module demonstrates a small isolated feature of the microcontroller.
